# AI Voice Hub — downloads

Disk images and the update feed for AI Voice Hub.

The application source is not here.

## Installing

1. Download the latest `.dmg` from [Releases](https://github.com/ghostdevai300-ctrl/AIVoiceHub-releases/releases)
2. Drag **AI Voice Hub** into your Applications folder — not Downloads, and not
   run from the disk image, or it will not be able to update itself later
3. The first launch is blocked because the app is not registered with Apple.
   Open **System Settings → Privacy & Security**, find AI Voice Hub, and choose
   **Open Anyway**

You only do step 3 once. Updates after that install themselves.

## Requirements

- macOS 14 or later
- [BlackHole](https://existential.audio/blackhole/) (`brew install blackhole-2ch`)
